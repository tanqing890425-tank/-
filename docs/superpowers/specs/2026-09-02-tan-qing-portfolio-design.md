# 谭清个人作品集网站设计说明

## 1. 项目目标

为 UI 设计师 / 视觉设计师谭清搭建一个适合 PC 端展示的个人作品集网站基础版本。网站需要在首次浏览时建立鲜明的个人审美，同时清晰传达八年 UI/UX 从业经验、多端产品能力、设计系统经验与代表项目。

第一版的目标是完整、可运行、可预览，并为后续替换真实项目截图、参考网站风格和案例详情预留稳定结构。

## 2. 已确认的设计方向

采用“编辑部肖像”方向：人物与排版主导，科技感通过影像质感、细节动效和界面秩序表达，不使用常见的霓虹渐变、发光按钮或模板化数据面板。

核心气质：暗色、高级、克制、冷静、个人化。

页面的记忆点是一套贯穿全站的“编辑切片”语言：人物影像、项目画面和大标题通过不对称裁切、细线分隔与局部铜色标记产生连续叙事。大胆表达集中在首页人物影像和大标题，其余区域保持安静。

## 3. 视觉系统

### 色彩

- 墨黑 `#090A0C`：页面主背景。
- 石墨灰 `#15171B`：卡片与分层表面。
- 骨白 `#E7E4DC`：主标题与关键文字。
- 雾灰 `#8D9197`：说明文字与辅助信息。
- 氧化铜 `#B48666`：按钮、状态和少量视觉焦点。
- 深铜 `#725440`：铜色的低对比阴影与悬停层次。

### 字体

- 中文标题与正文：优先使用现代黑体系统字体，保证 Windows 环境的稳定显示。
- 英文展示标题：使用高对比衬线字体，带轻微斜体，塑造编辑感。
- 标签与数据：使用紧凑的无衬线字体和较宽字距，承担信息索引作用。

字体加载失败时必须有稳定的本地回退字体，不影响版式和可读性。

### 版心与节奏

- PC 端最大版心约 `1700px`。
- 页面左右留白随视口伸缩；大屏保持宽阔，小屏不出现横向滚动。
- 内容模块以细线、留白和字号层级分隔，减少装饰性容器。
- 项目卡片使用非对称布局，首个项目占据更强视觉权重。

## 4. 页面结构

### 4.1 顶部导航

- 左侧为 `TAN QING®` 个人标识。
- 中部或右侧提供“关于 / 项目 / 优势 / 联系”锚点导航。
- 明确的“联系我”按钮跳转到底部联系模块。
- 页面滚动后导航保持可用，背景由透明过渡为半透明深色。

### 4.2 全屏 Hero

- 视口高度的首屏视频背景，桌面端优先展示。
- 视频采用本地、低饱和、慢节奏的抽象影像，不依赖外部资源。
- 视频上叠加人物肖像裁切、暗色遮罩和细微颗粒，确保文字可读。
- 主标题使用中英文组合，核心表达为“为复杂产品建立清晰而有温度的体验”。
- 辅助信息包括 `UI / VISUAL DESIGNER`、重庆、八年经验和可联系状态。
- 主操作为“查看精选项目”，次操作为“联系我”。

### 4.3 个人经历

- 三栏结构：人物图、个人介绍与职业时间线、数据和联系方式。
- 个人介绍基于简历，突出 App、H5、小程序、PC 后台和网站的全链路经验。
- 工作经历展示三家公司及时间：
  - 重庆惠融数字科技有限公司，2023.03–2026.08。
  - 重庆绿邦智联科技有限公司，2021.11–2023.02。
  - 重庆宇物科技有限公司，2021.04–2021.10。
- 数据展示使用真实且可验证的内容：八年工作经验、三段核心经历、三项代表项目、多端交付能力。
- 联系方式公开展示手机号 `17784453173` 和邮箱 `641103902@qq.com`。

### 4.4 精选项目

- 展示三个代表项目：
  - 安星融 / 车友花等金融助贷服务产品。
  - 桃乐 LBS 概念社交 App。
  - 喜拆拆潮物盲盒商城 App。
- 大卡片采用非对称网格。每张卡片包含项目名称、类型、时间、职责摘要和视觉封面。
- 第一版使用原创的抽象项目封面，不伪装成真实产品截图，并在数据结构中预留真实图片替换入口。
- 卡片悬停只做轻微图像位移、标题变化和细线展开，不使用夸张缩放。
- 第一版不制作独立案例详情页；点击卡片展示简短项目说明或保持静态，为后续扩展预留入口。

### 4.5 个人优势

- 四张能力卡片：
  - 全链路多端设计。
  - 设计系统与规范搭建。
  - 业务转化与体验优化。
  - AI 工具融入设计工作流。
- 卡片以内容和排版为主，图标仅作辅助，不使用统一模板插画。

### 4.6 全屏联系收尾

- 使用接近整屏高度的深色收尾页。
- 大标题邀请合作或交流，下方直接提供手机号与邮箱。
- 提供电话和邮件链接，点击可调用系统对应功能。
- 页脚保留个人标识、所在地与版权信息。

## 5. 内容与素材策略

- 个人信息、经历、项目与能力文案均以用户提供的简历为事实来源。
- 使用简历中的人物照片作为第一版肖像素材，并进行适合暗色背景的裁切与处理。
- Hero 背景视频在本地生成或制作，保证离线预览仍然成立。
- 项目封面为第一版原创抽象视觉，不使用未经授权的第三方项目图片。
- 后续替换素材时，尽量只更新资源文件和项目数据，不重写页面结构。

## 6. 技术架构

- 使用 React + Vite。
- 采用单页结构与语义化 HTML。
- 页面拆分为 `Header`、`Hero`、`Experience`、`SelectedProjects`、`Strengths`、`Contact` 等组件。
- 项目与经历数据独立存放，通过映射渲染，方便后续更新。
- 样式以普通 CSS 和 CSS 变量实现，避免引入不必要的 UI 框架。
- 使用原生 Intersection Observer 完成滚动出现效果，避免为少量动效引入大型依赖。
- 所有锚点跳转、电话和邮件操作在没有 JavaScript 增强时仍保持基本可用。

## 7. 动效策略

- 首次进入时只编排一次：导航、标题、辅助文字和操作依次出现。
- Hero 视频保持缓慢连续，不使用频繁闪烁或快速剪辑。
- 页面滚动时内容只做轻微透明度和纵向位移变化。
- 项目卡片悬停动效控制在短时间内完成。
- 检测到 `prefers-reduced-motion` 时，关闭背景视频自动播放和非必要动画。

## 8. 响应式与可访问性

- 重点适配 `1440px`、`1920px` 和更宽桌面显示器。
- 同时保证平板和手机宽度下可以正常阅读，布局按顺序折叠。
- 所有交互元素具有可见键盘焦点。
- 图片提供替代文本，视频提供静态回退画面。
- 正文与背景保持足够对比度。
- 导航、标题层级和分区使用语义化结构。

## 9. 验证标准

- 项目可以完成依赖安装、开发启动和生产构建。
- 在主流桌面浏览器中页面结构、视频、锚点和联系方式可用。
- 在 `1920px` 与 `1440px` 宽度下进行完整页面截图检查。
- 在窄屏下检查无横向溢出、文字遮挡或卡片断裂。
- 检查减少动态效果模式。
- 视觉检查必须确认：文字清晰、模块节奏稳定、项目封面不冒充真实案例、人物素材不失真。

## 10. 第一版范围边界

第一版不包含 CMS、后台、表单发送服务、独立案例详情页、多语言切换和线上部署。上述能力可在真实项目素材和参考网站补充后按需要增加。
